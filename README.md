Портал Департаменту стратегії універсального охоплення населення медичними послугами НСЗУ.

- Сайт: https://rpe-pmg.org.ua
- `library/` — відкрита бібліотека документів (роз'яснення, пакети, реєстр)
- `tools/` — службові скрипти збирання даних (запускаються локально)
- `05_Веб_реєстр/` — редіректи зі старих адрес, не видаляти до 2027

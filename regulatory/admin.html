🛠 Сервісні операції

Робота зі сховищами даних: хмара (Supabase) ↔ локальний статичний файл data/regulatory_documents.json.

🔄 Оновити статичний JSON Завантажує всі актуальні документи з Supabase і перезаписує локальний файл через сервер розробника (/api/save-data). Після цього зміни треба опублікувати на GitHub Pages.
📥 Ініціалізація хмари Якщо база Supabase порожня — завантажує початкові документи зі статичного файлу data/regulatory_documents.json у хмару.
📖 Як додати повний текст документа (навігація, дерево, пошук) 1) Створіть картку документа тут, в адмінці — номер документа є ключем зв'язки. 2) Вставте текст документа у будь-який ШІ-чат разом з готовим промтом з файла data/docs/_ПРОМТ_для_ШІ.md. 3) Збережіть відповідь ШІ у файл data/docs/<НОМЕР>.json (символи «/» у номері замініть на «_»).
